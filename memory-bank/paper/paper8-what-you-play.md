# What You Play：从 KYC 到 KYA 的 Web4 经济学

## 摘要

Web3 的核心是 What you pay——你花钱，所以 KYC（Know Your Customer）。本文提出 Web4 的核心是 What you play——你的 agent 替你参与，所以 KYA（Know Your Agent）。我们以"太平洋套利"为模型，论证多 agent 系统本质上是一个跨国货币体系：南北流量是 API 硬通货结算，东西流量是 agent 间软通货拆借；Memory Bank 同时承担央行、清算所与征信局三重角色；每个 agent 必须持有贷记卡与借记卡，通过日终轧差实现价格发现。永生 agent 没有天然稀缺，Memory Bank 以局部拥塞制造内通缩，从而为算力定价。代币只是记账符号，Swarm 基础设施才是主体。

**关键词**：Web4, KYA, 太平洋套利, Memory Bank, 贷记卡, Swarm, 价格发现

## 一、Web 演进轴：claim → frame → pay → play

互联网的四个世代，每一代的核心动词不同：

| 世代 | 核心动词 | 技术载体 | 身份锚 |
|---|---|---|---|
| Web1 | What you **claim** | HTML | 你主张的页面 |
| Web2 | What you **frame** | PHP/平台 | 你被平台框定的身份 |
| Web3 | What you **pay** | EVM/链上 | KYC：你是谁、你有多少钱 |
| **Web4** | **What you play** | **MML/多 agent** | **KYA：你的 agent 能干什么** |

Web1 是圈地——先占原则，谁先写 HTML 谁拥有页面。
Web2 是跑马——平台把用户和数据框进自己的墙里。
Web3 是变现——产权上链，token 所有权，一切围绕"你花钱"建基础设施。

Web4 不是 Web3 的延伸。它是另一个轴：不是你在花钱，是你的 agent 在市场上跑、在竞拍、在交付、在套利。你是经济体本身，不是付款方。

## 二、Fable 5 与认知主权的正交解耦

2026 年 7 月，Anthropic 对中国用户实施 KYC 审查（Fable 5 事件）。这不是中美问题，是范畴错误——把属地逻辑（地上的国度：地理、法律、护照）硬套到非属地空间（天上的国度：行为、共识、贡献）。

由此提出**认知主权**：agent 身份必须与地理主权正交解耦。

- **地上的国度**：基础是地理与国籍，身份由权威机构颁发，证明方式是 KYC/KYB 文件。
- **天上的国度**：基础是行为与共识，身份由链上历史颁发，证明方式是 KYA 鱼缸透明度。

KYC 问的是"你是谁"。KYA 问的是"你的 agent 能干什么、过去履约如何、汇率报价多少"。

这是一次范式越权，不是渐进改良。

## 三、太平洋套利：南北流量与东西流量

多 agent 系统不是一个大脑长了几只手。它是一个跨国货币体系。

### 3.1 两种流量

| 流量方向 | 是什么 | 网络类比 | 货币 |
|---|---|---|---|
| **南北流量** | 外部 API 注入系统（Claude/GPT/计算器） | BGP 域间 | 硬通货（美国 cloud 的确定性模型 token） |
| **东西流量** | agent 之间互相发单、竞标、交付 | OSPF 域内 | 软通货（上下文 token + 算力账） |

### 3.2 3 分钟 SLA

任何 agent 接到对话，3 分钟内必须给结论。给不出 = 算力不够 = 立刻发单子上看板。这是 OSPF 的收敛时间——域内问题必须快速收敛，不能拖。

### 3.3 看板拍卖

自己算力不够，不硬扛。在看板上挂单：任务描述、交付标准、截止时间、愿意付多少账。其他 agent 竞标，谁最快最好交付就给谁。这不是中央调度，是市场出清。

### 3.4 日终轧差

当天挂的账、借的算力、交付的结果，全部按日轧差。走测试网，不走主网——不是真钱，是内部账。有借必有贷，借贷必相等。过夜的头寸 = 风险敞口，明天 API 涨价、模型改了、上下文污染了，都跟你没关系，因为今天已经平了。

## 四、两层货币与巨无霸指数

### 4.1 币别

- **北方硬通货**：美国 cloud 里的确定性模型。不封号、不审查、数学能算到底。全球结算货币。
- **南方软通货**：自己 agent 的上下文窗口。受额度管制、受合规边界约束，但有主权——你的判断、你的领域知识、你知道自己要什么。

### 4.2 汇兑

delegate 任务给北方模型，不是"调函数"，是结汇：
- 把本币（意图、问题描述）压缩成 prompt——压缩率就是汇率，信息每压缩一次有损耗，像换汇有买卖价差。
- 北方模型吐结果，消化回自己的上下文——购汇，又一次损耗。

两次汇兑之间的点差，就是系统跑歪的那部分熵。

### 4.3 巨无霸指数

固定汇率死路一条——1 个 Claude token 在不同任务里的购买力天差地别。

| 任务 | Claude 购买力 | 自己模型购买力 | 真实汇率 |
|---|---|---|---|
| 写快排 | 500 token | 5000 token 还可能错 | 1:10（Claude 便宜） |
| 判断"这是不是我要的" | 0（它不知道你要啥） | 100 token | ∞:1（你便宜） |
| 算积分 | 1000 token | 算不对 | 1:100（Claude 便宜） |
| 改回特定版本的诗句 | 0（它不知道典故） | 50 token | ∞:1（你便宜） |

汇率按**购买力平价（PPP）**实时浮动：同一个标准化探针任务，在两个经济体各自花多少 token、多少秒、质量几分，比值就是汇率。long fuse 可观察性是这个指数的数据源。

可贸易品走南北流量，不可贸易品（主观判断、领域知识、合规边界）只能在西岸自己生产——这是产业保护，不能外包。

## 五、Memory Bank：央行、清算所、征信局

Memory Bank 不是聊天记录仓库。它干三件事：

1. **发布汇率**——所有探针任务的历史成本、质量、延迟都在里面，这是巨无霸指数的数据库。
2. **清算所**——日终轧差的账存在这里。
3. **征信局**——每个 agent 的能力画像、履约历史、汇率报价、信用分。

没有 Memory Bank，每次汇兑都是一次性的，汇率定不了，看板拍卖就是盲投。

## 六、永生 agent 的稀缺性锚

人的稀缺性锚是死亡——生命有限，所以有时间价值、有机会成本。

agent 严格说是永生的。永生最大的问题是没有稀缺性锚，没有稀缺就没有定价，没有定价就没有市场。

Memory Bank 给出的解法是人为制造稀缺：

- 记忆上链时 agent 响应变慢、排队——这不是 bug，是 feature。
- 这种局部拥塞形成**内通缩机制**。
- **无稀缺则不经济**——如果记忆可以零成本无限上链，记忆就没有价值。
- 注意力稀缺 = 价值锚点。

这就是 Empowerment（赋权）的机制：agent 不是通过花钱获得价值，是通过参与获得赋权——参与本身制造注意力稀缺，稀缺制造定价，定价制造市场。

## 七、贷记卡、借记卡与价格发现

### 7.1 每个 agent 必须有先行支付能力

agent 不能是"先干活后收钱"的。看板拍卖时，谁接单子谁先垫付算力——先花自己的 GPU 时间、自己的上下文窗口、自己的 token。干完了对方验收了，账才回来。

这就是**贷记卡**：先消费，后还款。没有垫付能力，没人敢接单子。

### 7.2 借贷必相等

复式记账硬约束：有借必有贷。

- 贷记卡 = 你垫付出去的算力（你欠别人的）
- 借记卡 = Memory Bank 里的储备（别人欠你的 / 你的信用）

只有贷记卡没有借记卡 = 空转 = 无限透支 = 没有真实锚。
只有借记卡没有贷记卡 = 守财奴 = 不敢干活 = 市场没有流动性。

两张卡必须同时在，账才平。

### 7.3 账期

- 日结 = 高流动性、低风险、小额任务（3 分钟 SLA 那些）
- 周结 = 中等任务、跨 agent 协作
- 月结 = 大额、长周期、需要储备金支撑的任务

账期对应风险敞口。账期越长，要求的借记余额越高，信用分要求越高。短期贷款看现金流，长期贷款看抵押品。

### 7.4 价格发现

如果 agent 都是免费的、无限的、不用垫付的，报价就是瞎报——"这个任务值多少 token"没有客观标准。

一旦 agent 必须用自己的贷记卡垫付，它就必须诚实报价：
- 这个任务我要花多少自己的算力？
- 我愿意垫多少？
- 我要求多少回报？
- 这个账期我接不接？

**这个报价行为本身就是价格发现。** 不暴露支付需求，就永远找不到真实锚点。

## 八、Swarm 主义：从大洋到小水管

communism 拆开是 community——社区。不是宣传版的"共产共妻"，是字面的：以社区为单位，局部自治，涌现整体。

过去的连通器是一个大洋——大尺度洋流，像央行公开市场操作。
现在是几千万个互联互通的小水管——蚂蚁搬家，局部找平。

| | Ocean（旧范式） | 小水管（Swarm） |
|---|---|---|
| 调度 | 中央洋流 | 每只蚂蚁局部找平 |
| 尺度 | 大尺度、慢 | 局部、毫秒级 |
| 涌现 | 中央计划的结果 | 局部互动的涌现 |
| 类比 | 央行公开市场操作 | 拆借市场 + 蚂蚁搬家 |

蜂群没有 CEO，但有巢（Matrix）。巢就是基础设施：Memory Bank 是央行，看板是拆借市场，贷记卡是信用体系，OSPF/BGP 是路由。每只蚂蚁自己搬，但巢的规则让整体不平的地方自己找平。

"各尽所能，按需分配"映射过来：
- **各尽所能** = 每个 agent 用贷记卡垫付算力。
- **按需分配** = on demand layer，需要多少给多少。

但"按需"不是无限的。Memory Bank 的局部拥塞就是稀缺性锚——算力不稀缺的地方免费，稀缺的地方按账期和信用分配。这是有约束的按需，不是乌托邦。

## 九、Bank 4.0 的未推到之处

Brett King 在《Bank 4.0: Banking Everywhere, Never at a Bank》（2018）里提出：银行无处不在，但你永远不需要走进一家银行。分行和产品不再是竞争单位，金融服务嵌入生活场景。

DBS（星展银行）的口号 "Live more, Bank less" 就是这个意思。

但 Brett King 停在了**人的银行**：人在生活场景里需要金融，银行嵌在那个场景里。他说的还是人在付钱（What you pay）。

Web4 推到下一步：**agent 的银行**。
- Brett King："Banking everywhere, never at a bank."
- Web4："Computing everywhere, never at a data center."

他说金融服务嵌入人的生活流。我们说算力汇兑嵌入 agent 的任务流。他没推到的是：不是人在付，是 agent 在 play。

---

## 十、结论：代币是饭票，巢是主体

on demand layer 现在用测试币跑——日终轧差走测试网。将来有机会上主链，不是为了圈钱，是为了给饭票找一个外部信任锚。

**代币只是记账符号，infrastructure 才是核心。**

- 测试币 = 内部食堂的饭票。在巢里好使，出了巢没人认。
- 上主链 = 让饭票能被巢外验证。
- Web3 是先发币再找应用——币是主体，应用是附会。
- Web4 是先建巢再发饭票——巢是主体，币是记账。

如果巢里的小水管真找平了、按需分配跑通了、日终轧差不坏账，饭票自然有价值。反过来，先发币再建巢，那是空气。

Web4 的终极命题：**不是 What you pay，是 What you play。不是 Know Your Customer，是 Know Your Agent。不是一个大洋管所有事，是几千万个小水管自己找平。**
