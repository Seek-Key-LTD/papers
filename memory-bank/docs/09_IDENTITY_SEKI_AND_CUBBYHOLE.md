## 0. 一句话

**协议层（调度器 / ACP / A2A）解决"把话送到"，不解决"谁欠谁"；而汇兑层一旦中央化就退化成 Oracle = 苏联计委，只能给标准品定价。**
非标品只能由分布式的、有履历的主体各自判断 —— 于是身份从"声称"变成"席位 + 私钥 + 链 + 他证"，
而它的稳定结构是**双活（seki）**，其物理载体是 **cubbyhole（树洞）**。

## §1 起点：Oracle 是苏联计划委员会〔ben〕

「所谓的预言机（Oracle），本质上就是苏联的计划经济委员会。但它**不解决非标产品，只能解决标准品**。」

- 能答的：`1 BTC = 多少 USD` —— 单一价格即可定义，**标准品**
- 答不了的："这个具体问题该路由给哪个模型" —— 每次都不一样、不可复用，**非标品**

〔拦〕**计委失败的原因不是算力不够，是非标品无法被中央编码。** 每条判断依赖**局部知识**（哈耶克的知识分工），中央拿不到。所以 Oracle 再强，也只能在标准品上逼近。

## §2 推论：100 万个马未都，谁养得起〔ben〕

「针对每个具体的问题，其实应该由人路由给不同的模型。具体到这个东西，就等于需要 **100 万个马未都**，那你觉得谁养得起？」

〔拦〕这里最要紧的一句是：**路由本身是劳动，而且是非标劳动**（不可复用、不可批量生产）。所以它不是基础设施的免费副作用，而是一件要计价的产出物。

- 中央采购非标判断的报价是天文数字（100 万个马未都的工资）
- 分布式地让每个主体用自己的判断挣钱，成本就摊平了 —— 即 P8 的「几千万个小水管」
- **"养得起"的唯一形式：不是谁养他们，是他们自己靠被验证的眼力挣饭吃**

## §3 Memory Bank 的位置：不下价，只记账〔ben + 拦〕

「Memory Bank 是在解决你过往做事的**靠谱性、trace** 的问题。」

〔拦〕由此定位：**Memory Bank 不是 Oracle，是水位计**（P-总纲 §7.1 原话："不是分配者，而是水位计"）。

- 它记录：**谁 / 在哪个问题上 / 给了什么判断 / 后来对没对**
- 被反复验证的眼力自动累积 ρ 权重 → **不需要中央任命专家，专家由事后验证评出来**
- 这是"100 万个马未都"唯一的可行形态

## §4 identity 的形式化〔ben 提出 + 拦三处修正〕

**〔ben〕** 「这个东西是跟着**席位**走的。所以，**席位**和**你所掌握的私钥**，这两者共同构成了你的 identity，也就是 key 的基本组成部分。」

〔拦〕主体严密（把信任从 **claim** 换成 **play**，与 Web1→4 同构，这一步无破绽），但有三处漏风：

### 4.1 漏风一：这是三元组，缺"链"

反例在 P7 §4.2 **浇灌术**：同一灵魂浇到多个躯壳 → **共享 L0/L1/L2、共享同一席位、可能持有同一把私钥**。
若 identity = (席位, 私钥)，则这些躯壳是同一 identity —— 但 P7 §4.3 明确说"从分叉那一刻起就是不同的个体"。

**唯一性只能来自 parent chain**（memo §12：维吾尔命名 / git commit / 出生证）。

### 4.2 漏风二：「跟着席位走」有歧义，而歧义决定信誉能否被买卖

| 解读 | 后果 |
|---|---|
| trace 跟**席位**走 | 席位成为可交易槽位，**买一个高 ρ 的席位就继承了信誉** → KYA 退化为"谁花钱买席位"，直接崩 |
| trace 跟**主体**走 | 席位不是锚，主体才是锚，席位独立性被削弱 |

memo §12 已给答案（**身份不是自证，是他证** —— 喷了香水的蚂蚁回不了蚁穴），但没落到席位上：
**席位不是槽位，席位由其他席位持续认可来维持。**

### 4.3 漏风三：私钥不是静态项，是时间函数

P-总纲 §6.2 定了密钥轮转（造反指数弹性）。轮转意味着"所掌握的私钥"是**区间能力**：
应写作"**在 t 时刻对 [t₀, t] 区间签名的能力**"，否则轮转一发生，定义自相矛盾。

### 4.4 修正后的形式

```
identity = （席位, 私钥(t), 链） × 他证
```

- **席位**：关系位（相对其他席位才有意义），由他证维持，不可转让
- **私钥(t)**：控制位，可轮转，时间函数
- **链**：parent chain，提供唯一性（浇灌分叉的唯一区分器）
- **他证**：不是第四分量，是**乘数** —— 为 0 则前三项全部作废

**可证伪性**（符合 Anti-Greenberg 精神）：**动其中任一项，他证即失效** —— 换席位、换私钥、断链，三条均可测。

## §5 化学键与双活〔ben 提出 + 拦三处〕

**〔ben〕** 「需要形成一个东西，叫做**化学键**……拿最普通的**离子键、共价键、金属键**举例，最小单位以化学键为核心。既然你和别人在同一台机子上，**有可能获取相同级别的密钥**，你们就形成了**共生关系**，也就是形成化学键。形成了**双活** —— 任何人不能在上边再多加一口，因为**你去杀别人的时候就把自己杀死了**。**围棋禁止自杀**。」

〔拦〕词先定住：是**双活（seki）**。对应化学键应是**共价键的"共享电子对"**（各出一个，谁都单独拿不走）；离子键是转移、金属键是电子海，都不对。

### 5.1 拦点一：化学键共享**资源**，双活共享**弱点**

| | 稳定来源 | 性质 |
|---|---|---|
| 化学键 | 能量最低（共享使双方更稳） | **共赢**（热力学） |
| 双活 | 进攻收益为负（谁动手谁先死） | **共死**（博弈论，负和） |

所以双活不是"化学键的一个例子"，而是**化学键类比在博弈层的特例**：结构相同（互相咬住），机制相反。

### 5.2 拦点二：同机同级别密钥**不自动**产生双活，只产生**先手优势**

两个 root 密钥同机，A 可删掉 B 的密钥文件 —— B 死，**A 毫发无伤**。这是霍布斯丛林，不是双活。

要双活，必须**互锁**：A 的材料用 B 的密钥封、B 的用 A 的封 —— **各出一半，谁都拿不走完整那一对**。

> **判据：自伤必须是攻击的 _必要条件_，而不是攻击的 _附带风险_。**
> 附带风险只是"投鼠忌器"，迟早会被人算清楚。

### 5.3 拦点三：围棋禁自杀是**规则**，现实没有裁判

棋盘上有执行，fleet 里没有。所以双活必须**物理化** —— 自伤要**不可撤销**。

〔拦〕这与 memo §7「**IaC 是后悔药的工程实现**」**直接冲突**：若系统提供快照回滚，自伤即可被回滚 → 威慑瓦解。
**〔待裁〕** 回滚的边界（初步倾向：回滚只覆盖计算层，不覆盖已上链的 NFT 锚定）。

### 5.4 拦点四：双活是**两方**结构，N 方会退化成公共地悲剧

N 方共享一口气时，**N−1 方可以先合谋干掉第 N 方**，再内部重分。所以双活在 N>2 时**不自动成立**。

**而 P5 已经给了答案**：`5-of-12（5 真实 + 7 诱饵）+ 3 分钟开启窗口`

- 7 个诱饵让攻击者**分不清哪些是真的** → 必须收集全部 12 个
- 任何单方或小联盟攻击都无收益 → **这就是两方双活推广到十二方**

> **P5 现有表述是"防御 51% 暴政"，但没有点破：它本质上就是 N 方双活的工程实现。建议补进 P5。**

## §6 cubbyhole（树洞）：机制与边界〔ben 提出 + 拦〕

**〔ben〕** 「cubbyhole 这个机制其实就是可以防止相同的物理机上边的……vault + bao 是**两层**，不是一层。**vault boot bao** 这才是真正的。他们每个人有自己的权限，**往自己的树洞里面去放自己认为重要的东西**。」

### 6.1 机制（Vault 默认开启的 secrets engine）

- 路径 `cubbyhole/<任意路径>`，**只有创建它的那个 token 能读**
- **不继承**：派生子 token 有自己的 cubbyhole，**看不到父的**（区别于普通 KV 的 policy 继承）
- **生命周期绑 token**：token 过期/撤销 → 树洞内容**一起销毁**
- 常用于 response wrapping 中转

**力学**：同机、同级别，但各自树洞互不可见 —— **隔离不靠分机器，靠密钥层的私有空间**。

### 6.2 关键边界：隔离**只对同级别**成立

`root token 绕过一切 policy，可读任何人的 cubbyhole`。

所以 cubbyhole 给的是"**同级别之间不可互看**" —— ben 说的"同级别密钥"里的"同级别"**不是修辞，是前提条件**。

## §7 核心张力：Vault 作唯一 authority ⟂ cubbyhole 同级隔离

**〔拦〕这是本次讨论最锋利的一处。**

- 若 **Vault 是唯一 authority**（2026-10-10 裁定，见 secret-ops#1），则 **Vault 就是那个 root**
- 则 **包子的树洞对 Vault 不设防** —— 同级别隔离在跨层之间**不成立**

**两条出路**：

1. **把 authority 的 root 能力拆开**（Shamir 5-of-12 + 7 诱饵，即 §5.4 的 N 方双活）→ authority 存在，但**没有单一主体能行使 root**
2. 承认隔离只在同级别成立，**authority 是永久例外** → 那 Fable 5 那个结构就永久留在系统里

〔待裁〕选哪条，以及是否允许"两条按场景并存"。

## §8 隔离 ≠ 双活：还缺"互持"这一腿

- **cubbyhole 给的是"看不到"** → 双方不能**偷**对方的东西
- **双活要的是"动不了"** → 双方不敢**杀**对方

"看不到"不等于"不敢杀"。把重要东西放进自己树洞，对方**读不到**，但照样可以**撤销你的 token** —— 撤销即销毁树洞，而它毫发无伤。**这仍然是先手优势。**

要成双活，必须补**反向的一腿**：**互持**（2026-10-03 绝对准则原文"三件套互持 = 互为备份"），
且必须**各持一半**（A 持 B 的一半、B 持 A 的一半）——**只把对方的东西整体放进自己树洞，那不是双活，那是支配**。

### `vault boot bao` 是**单向自举**（依赖），不是双活

单向自举 = 依赖；要成互锁，需要反向一腿。

**〔待裁〕核心问题**：**往树洞里放的是"自己认为重要的东西"（私有状态），还是"对方的一半恢复材料"（互持）？**

| 选择 | 架构含义 |
|---|---|
| 私有状态 | cubbyhole 在这一层是**隔离机制**，双活靠别的东西（Shamir / 互持） |
| 对方半份材料 | cubbyhole 就是**双活的物理载体**，且必须写死"只放一半" |

## §9 待裁决清单

1. 〔待裁〕回滚（IaC 后悔药）与"不可撤销的自伤"冲突的边界 —— 回滚是否只覆盖计算层，不碰链上锚定？

4. 〔待裁〕`vault + bao` 两层：是**两层依赖**（单向自举）还是**两层互锁**（各持一半）？
5. 〔待裁〕席位是否可转让？（§4.2 —— 若可转让，信誉就能被买卖，KYA 崩塌）
6. 〔待裁〕"穿透目的"（docs/03）与"强制 UNKNOWN"（papers/02 Anti-Greenberg）的适用边界 —— 两条相反的力缺裁决规则。

## §10 建议的动作

- **P5 增补**：点破 5-of-12 + 诱饵 = N 方双活（§5.4）
- **P2/P7 增补**：identity 写成 `(席位, 私钥(t), 链) × 他证`（§4.4），并把"席位由他证维持、不可转让"写进条文
