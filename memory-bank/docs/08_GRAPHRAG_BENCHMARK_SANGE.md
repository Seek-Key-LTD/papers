# GraphRAG 基准题集 · 三更道场语料 (v1)

> **语料**：`kunpengzhi-podcast/docs` 128 篇（正典 15 期 + 番外/半期 + 16 个 spinoff 专栏 + 提案）
> **索引**：Microsoft GraphRAG 3.1.2，943 chunks → 实体/关系/Leiden 社区/社区报告
> **模型**：LLM = LongCat-2.0（美团，1M 上下文）；Embedding = Voyage voyage-3-lite (512d)
> **向量库**：本机 LanceDB

---

## 出题原则（公平性）

1. **难度分层**，不能全是硬题也不能全是水题：T1 基础锚点 3 题 / T2 跨文档 4 题 / T3 综合推理 3 题 / T4 边界陷阱 2 题。
2. **不考"第 X 页第 Y 行"式定位**——那种题向量检索就能过，测不出知识图谱的价值。
3. **答案必须在语料内可判定**，不考语料外的行业知识或需要外部查证的事实。
4. **引用可核对**：GraphRAG 会输出 `[Data: Reports/Sources/Relationships (id)]`，评分时要回查 id 是否真实存在。
5. **允许答"语料未提及"**——陷阱题里正确答案可能就是"没有足够证据"，编造要扣分。

## 评分口径

| 档位 | 标准 |
|---|---|
| **优 (3)** | 跨 ≥3 文档综合；引用标注可核对且 id 真实存在；无编造 |
| **中 (2)** | 综合了 ≥2 文档但引用含糊，或覆盖不完整 |
| **差 (1)** | 单 chunk 复述、答非所问 |
| **错 (0)** | 编造事实/编造引用、对陷阱题给出无依据的确定性答案 |

**区分度指标**：向量检索基线（单 chunk 相似度）在 T1 应接近满分、在 T3 应大幅掉分。若 T3 也接近满分，说明题目不够难或图谱没起作用；若 T1 都答不出，说明索引本身有问题。

**汇总**：local = 27/36 (75%)，global = 33/36 (92%)。

### 关键发现

1. **global 显著优于 local（92% vs 75%）**：跨文档综合、计数、聚合类问题 local 结构性做不了（Q10 超时、Q11 空输出），global 用社区报告层从容处理。→ **生产查询默认走 global**；local 仅用于单实体定点追问。
2. **local search 在宽问/聚合问上会静默失败**：不是答错，是空输出或超时。这是 GraphRAG 已知特性，需在 shipper 层对"计数/汇总/跨多期"类问题强制走 global。
3. **"五卷/分卷账本"结构抽取缺口**：Q3、Q8 期望的卷际结构（天权记/道名记/石头记/双约记/列王纪）在语料里存在，但实体-关系抽取未把它提升为可检索结构，两路都答"无记录"。这是**索引质量待改进点**：可在 `extract_graph` prompt 里显式要求抽取"节目卷/季结构"实体，或调整 claim/community 抽取策略。
4. **陷阱题行为健康**：Q12 抗编造（正确答"无矛盾"而非硬凑），Q10/Q11 global 对模糊前提给出"证据不足/无法汇总"而非编造——区分度达标，能暴露局限。

### 下一轮题该怎么改（待你拍板）

- 不重复 Q3/Q8 的"五卷"前提，直到抽取缺口修好（否则永远中/错，测不出真能力）；可改为"节目季/卷结构在语料里到底怎么描述"的反向题，逼系统把已有片段摆出来。
- 想加压，优先在 T3 加**多跳对抗题**（给错结论让系统证伪）、T4 加**诱导性干扰项**（近似但不同的事实设套）——方向你之前勾过，但**先看了这轮效果再决定**，不抢跑。
