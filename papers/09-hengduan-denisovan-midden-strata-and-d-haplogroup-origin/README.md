### 摘要 (Abstract)

长期以来，西方主流分子人类学基于 Haber et al. (2019) 在西非尼日利亚现代人群中检测到的 3 例稀疏样本（被赋予 "D0" / "D*" 标签），构建了 Y 染色体单倍群 D 起源于西非几内亚湾、并经由印度洋海岸线单向扩散至东亚与青藏高原的脆弱叙事。本研究指出，该假说在数学上属于严重的边界采样病态反问题（Ill-posed Inverse Problem），且面临“非洲本土零例古 DNA”、“无同位素人地绑定”、“无连续地层层位”的三重硬伤。

近期云南横断山脉（金沙江—澜沧江—怒江流域）古人类遗址出土的大规模、深厚度、连续数万年的**丹尼索瓦人长期聚居生活堆积层（包含高密度用火灰烬、敲骨吸髓的动物烧骨、高密度重型石器与打制废片）**，为东亚本土古人类演化提供了决定性的实物地层锚点。

结合**古水文大湖文明模型（Mega-Lake Civilization, MLC）**、**冰期低海平面海陆走廊**与**古基因组学证据（EPAS1 抗缺氧基因及高比例丹尼索瓦渗入率）**，本研究提出**“横断山脉河谷反应堆与 D 谱系双向离心模型”**：
1. 横断山脉纵向峡谷群是东亚丹尼索瓦人与早期现代人交汇繁衍的超级家园；
2. 向上溯流进入青藏高原封闭大湖系统，获得 EPAS1 基因并演化为高原 D-M174（D1a1），奠定象雄与古藏族底层；
3. 向下沿萨尔温江（怒江下游）与伊洛瓦底江切入孟加拉湾与安达曼海，在末次盛冰期（LGM）陆桥期直达安达曼群岛，完美自洽解释了“安达曼原住民兼具高频纯血 D 单倍群与高丰度丹尼索瓦基因”的世纪难题；
4. 构筑起北起周口店（40ka 田园洞人 K2a）、中贯横断山脉丹人家园、南抵大洋洲美拉尼西亚的东亚大陆内陆中轴动脉，彻底终结几内亚湾商港采样假象，为地层实测兑现【D-1】奠定实证基石。

### 一、 实物地层学对账：生活垃圾层（Occupation Midden） vs. 殖民商港 3 例现代噪点

西方“走出非洲”单系树状模型在解释 D 单倍群时，其证据链存在致命的非对称性：

| 证据维度 | 西非几内亚湾“D0”假说 (Haber et al. 2019) | 云南横断山脉丹尼索瓦人家园堆积层 (本模型锚点) |
| :--- | :--- | :--- |
| **样本属性** | 仅 3 例现代活人抽样（尼日利亚沿海港口） | **真实原位古人类生活遗址（In-situ Habitation Midden）** |
| **古 DNA 支撑** | **非洲本土迄今 0 例古 DNA** 检出 D/D0 | 骨骼化石、沉积物环境 DNA（sed-aDNA）与蛋白质组学多重确认 |
| **地层连续性** | **0 地层**。无法证明其祖先 7 万年前生活在此 | **厚达数米、连续数万年的生活堆积层**（非临时狩猎站） |
| **生活实证物证** | 0。无任何伴出的人类家园生产生活器物 | **大量高密度用火灰烬、灶坑、敲砸剥食烧骨、打制石核与废片** |
| **地理与经济学背景** | 近代大西洋跨洋奴隶/黄金/象牙商港，流动人口汇聚极值点 | 青藏高原东南缘高山峡谷天然避难所与古水系交汇枢纽 |
| **人地绑定机制** | 无锶（$^{87}\text{Sr}/^{86}\text{Sr}$）、氧（$\delta^{18}\text{O}$）同位素，不排除二次捡骨迁徙 | 原生土质与阶地熔岩完全咬合，无空间漂移扰动 |

**法医定性**：在近代殖民商港捞出 3 个现代流动人口样本，强行逆推 7 万年前的人类祖居地，本质上是用**“大英博物馆里找到一张大明宝钞，便推论造币厂在伦敦”**的幸存偏误。横断山脉厚重的“生活垃圾层”证明了这里是古人类连续扎根、繁衍生息的超级母体，具有不可辩驳的优先地层法统。

### 二、 横断山脉“水网反应堆”与 D 单倍群双向离心扩散

云南横断山脉独特的“高山深谷、多江并流”地理格局，构成了天然的基因隔离、混合与定向输送系统：

```
                    [青藏高原大湖盆地 (MLC)]
                    (玛旁雍错 / 阿里古湖 / 纳木错)
                                ▲
                                │ 向上攀登 (溯金沙江/澜沧江上游)
                                │ 固化 EPAS1 抗缺氧基因
                                │ 演化为藏族/象雄 D-M174 (D1a1)
                                │
               ┌────────────────┴────────────────┐
               │    云南横断山脉丹尼索瓦人家园    │
               │   (连续生活垃圾层 / 灰烬 / 烧骨) │
               │     【古 D 系与丹人超级基因反应堆】    │
               └────────────────┬────────────────┘
                                │
                                │ 向下俯冲 (沿怒江-萨尔温江 / 伊洛瓦底江)
                                │ 末次盛冰期 (海平面 -120m 陆桥通道)
                                │ 携带高丰度丹人基因与高频 D 谱系
                                ▼
                    [安达曼海与安达曼群岛]
                 (昂格人 Onge / 贾拉瓦人 Jarawa:
                   纯血 D 载体 + 高比例丹尼索瓦渗入)
```

#### 1. 向上攀登：高海拔适应性与青藏高原大湖文明（D1a1）
* 早期现代人人群沿横断山脉峡谷向上追溯水网，进入青藏高原封闭大湖盆地；
* 在横断山脉及高原边缘，与长期定居此处的丹尼索瓦人发生深度基因渗入，捕获了对极端低氧高寒环境至关重要的 **EPAS1 基因突变**；
* 这一适应性突变迅速形成强烈的正向自然选择扫荡，使得携带 D-M174 的先民在高原腹地迅速站稳脚跟，演化为古象雄文明与藏族的主体基因底座。

#### 2. 向下俯冲：解开“安达曼孤岛之谜”（D 与丹尼索瓦基因共存）
* **既往学术死结**：安达曼群岛原住民（昂格人、贾拉瓦人）几乎全员携带高频纯血 Y 单倍群 D，同时全基因组检测出极高比例的丹尼索瓦人基因渗入。按照西方“走出非洲沿海岸线快跑”模型，丹尼索瓦人分布在寒冷西伯利亚和青藏高原，赤道印度洋孤岛上的矮黑人为何能跨越数千公里获得如此高丰度的丹人基因？
* **本模型破局**：横断山脉的**萨尔温江（怒江下游）**与**伊洛瓦底江**直接注入安达曼海。在晚更新世末次盛冰期（LGM），全球海平面下降达 120-130 米，安达曼海周围陆桥大面积出露。横断山脉丹尼索瓦人基因反应堆孕育出的 D 系人群，顺江而下，无需任何长途大洋漂泊，沿着河口与近岸陆桥自然扩散至安达曼群岛，并因海侵海平面上升被天然隔离，成为全球保存最为纯粹的“横断山脉古基因活化石”。

### 三、 东亚大陆南北中轴动脉的完整合龙

横断山脉丹人家园的实物锁死，与华北周口店遗址构成了东亚古人类迁徙的南北中轴脊梁：

1. **华北周口店（40ka 田园洞人 K2a）**：
   确立了现代欧亚大部分人群（NO、P、Q、R）以及向美洲扩散的早期分化基部；
2. **西南横断山脉（丹尼索瓦人超级生活堆积层）**：
   确立了 C、D 单倍群与古老型人类（丹尼索瓦人）长期共生、混血并向高原与赤道海岛分流的核心枢纽；
3. **东南与大洋洲（美拉尼西亚 4-6% 丹人基因带）**：
   通过巽他古陆与内陆河谷溢流，与华南海陆走廊形成闭环。

整条欧亚大陆东侧的迁徙脉络，完全依托内陆大江大河与大型湖泊水网（MLC）的梯级阶地展开，不仅食物充沛（动物烧骨与渔猎堆积）、避风避寒（高山喀斯特洞穴），而且具备连续 tens of thousands of years 的地层序列支撑，无需借助于西方缺乏物理细节的“非洲赤道狂奔上万公里”假想。

### 四、 《三更道场》【D-1 证伪测试】的实操兑现路线

国际 Y 染色体命名协会（ISOGG）命名法规定，“0”后缀（如 A0、D0）仅代表在已知样本树中最深、尚未找到更早祖先时的暂时代号（2013 年 Albert Perry 样本直接逼迫学界新设 A00 即为明证）。

本模型明确建立如下实操证伪预言：
* **地层目标**：青藏高原古湖泊相沉积物（如阿里古湖、纳木错深钻）、横断山脉深层溶洞堆积；
* **测试标准**：一旦从横断山脉或高原古湖盆地层骨骼或沉积物环境 DNA（sed-aDNA）中提取出先于现代 D 分化支节点的古老型 Y 染色体序列；
* **法统命名**：直接授予 **【D-1】（D minus one）**；
* **结论**：西方基于几内亚湾商港 3 个噪点编造的“西非起源假席子”将彻底作废，全球人类单倍群多样性中心正式回归亚洲大湖与横断山脉腹地。
